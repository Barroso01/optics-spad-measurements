
This project established an experimental framework to characterize Single Photon Avalanche Diodes (SPADs) and classify the statistical properties of various light sources.
Hardware baselining accurately quantified intrinsic detector parameters, including dark count rate, dead time, afterpulsing, and jitter.
The setup successfully validated expected Poissonian distributions for coherent lasers and super-Poissonian distributions for thermal sources.
Time-Correlated Single Photon Counting (TCSPC) enabled precise second-order coherence ($g^{(2)}$) measurements to further differentiate emission regimes.
Careful optical path calibration ensured high-resolution detection of true coincidence events.
Ultimately, this methodology accurately captured intrinsic source statistics while accounting for detector artifacts, clearly distinguishing between classical and non-classical light.
