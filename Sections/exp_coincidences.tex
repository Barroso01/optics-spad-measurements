\subsection{Correlation Value}
\label{subsec:CorrVal}
First measurements measure second order coherence at $\tau = 0$ i.e $g^{(2)}(0)$. The procedure is given bellow. 
\begin{enumerate}
    \item Feed the Pulsed Laser into the optical setup in figure \ref{fig:exp_lay}. 
    \item Select a Laser frequency: $1/T_{dead} \approx 2\cdot10^8 = 200 MHz$  . 
    \item Select Exposure Time. 
    \item Connect Laser Sync and SPAD channels into the time tagger. 
    \item Measure timestamps of detection events. 
    \item Compare Channel Ticks. 
    \begin{itemize}
        \item[]  $\Delta t_{coincidence} = \Delta t_{B} - \Delta t_{A} $
        \item[] Coincidence if $\Delta t_{coincidence} \leq 2 \cdot Jitter$
    \end{itemize}
    \item Calculate Probabilities 
    \begin{itemize}
        \item[] $P_{A|B} = \frac{\# Events_{A|B}}{\# Pulses}$
        \item[] $P_{AB} = \frac{\# Coincidences}{\# Pulses}$
    \end{itemize}
    \item Calculate Correlation 
    \begin{itemize}
        \item[] $g^{(2)}(0) = \frac{P_{AB}}{P_{A} \cdot P_{B}} $
    \end{itemize}
    \item Check 3, 4 fold correlations $g^{(3)}, g^{(4)}, ...$
\end{enumerate}

\subsection{Correlation Function}
Second measurements designed to extract the second order cohrence function $g^{(2)}(\tau)$. 
\begin{enumerate}
    \item Feed the Pulsed Laser into the optical setup in figure \ref{fig:exp_lay}. 
    \item Select a Laser frequency: $1/T_{dead} \approx 2\cdot10^8 = 200 MHz$.
    \item Build Histogram of $G^{(2)}(\tau)$
    \item Normalize histogram by the average count of the time bins far from $\tau  = 0$ to get $g^{(2)}(\tau)$. 
\end{enumerate}

We expect $g^{(2)}(0) = 1$ with a comb structure for the Pulsed Laser. 
In contrast, for thermal sources, $1 < g^{(2)}(0) \leq 2$ and decays over coherence times. 
The width of this decay is a measure of the coherence time \footnote{Set by the diffuser speed}.
