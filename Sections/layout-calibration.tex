\subsection{SPAD Characterization}
With the set up complete, a SPADs calibration is performed to set the operational baseline for the subsequent measurements.
The SPAD is configured with a $V_Op = need to measure$ with the adjustment trimmer potientiometer and deadtime potientometer. 
We fix the configuration mid-range for optimal performance and proceed to extract the performance indicators. \\

First, a dark count experiment where we run the \texttt{tt.Countrate} function. 
We integrate 205 measurements give dark counts of $9.74 \hspace{0.1cm} cps$ and $10,301.49 \hspace{0.1cm} cps$ for SPAD A and B respectivley at this specific configuration.
Next, we extract the dead time of the detector, and afterpulsing probabilities with the procedure listed bellow: 
\begin{enumerate}
    \item Connect the CW LASER source to the fiber optics line feeding the system. 
    \item Connect the SPAD detectors with SMA Cables to Swabian Time Tagger. 
    \item Initialize the autocorrelation measurement (\texttt{tt.Correlation}) using a single SPAD channel as both the "start" and "stop" trigger. 
    \item Wait for detection events to accumulate for 10 seconds.
    \item Extract dead time and afterpulsing probabilities from data (See figure \ref{fig:autocorr}).
    \item Repeat for 5 time to gather Statistics. 
\end{enumerate}

\begin{figure}[htpb]
    \centering
    \includegraphics[width=0.5\textwidth]{Figures/autocorr_measurement.png}
    \caption{Autocorrelation histogram of the SPAD channels. Dead time is extracted from the temporal delay required for counts to recover from zero. Afterpulsing is extracted from taking the ratio of excess detections following the dead time to the total number of detections}
    \label{fig:autocorr}
\end{figure}

The \texttt{tt.Correlation} time tags a series of detection events, calculates the time difference between all events ($\tau$) and builds a histogram out of the number of detections that correspond to a particular time delay. 
Thus, from figure \ref{fig:autocorr}, we identify the total number of detections in bin $\tau = 0$ and the deadtime as the zero detection plateu. 
Afterpulsing is extracted as a ratio of excess detections that follow inmediatly after the deadtime to the total number of detections. The results are summarized in the table below:
